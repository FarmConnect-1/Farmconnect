# 🚜 FarmConnect

**FarmConnect** is a cross-platform agricultural marketplace app built with **Flutter** and **Firebase**. It enables direct connections between **farmers**, **retailers**, and **transporters**—eliminating middlemen, ensuring fair trade, and promoting digital inclusion in rural areas.

---

## ✨ Features

- 🔐 **Multi-role Login System**  
  Secure logins for **Farmers**, **Retailers/Consumers**, and **Transporters**.

- 📦 **Crop Listing & Price Locking**  
  Farmers can list produce, lock prices, and manage live market orders.

- 💬 **Real-time Chat System**  
  Seamless communication between:
  - Farmer ↔ Retailer  
  - Retailer ↔ Transporter  
  - Farmer ↔ Transporter  

- 🧠 **ML-based Fruit Ripeness Detection**  
  Upload photo/video to get ripeness percentage using a custom-trained ML model.

- 💰 **Instant Billing System**  
  Generate real-time invoices after each transaction.

- 🌍 **Multilingual & User-Friendly UI**  
  Simplified interface for rural users with regional language support.

- 📍 **Logistics Coordination**  
  Integrated flow between retailer and transporter for optimized delivery.

- 🧾 **Aadhaar & Kisan Praman Patra-Based Verification**  
  Ensures secure and authentic user onboarding.

---

## 🧑‍💻 Tech Stack

- **Frontend:** Flutter (Dart)  
- **Backend & Auth:** Firebase, Firefoo  
- **ML Model:** TensorFlow/Keras (fruit ripeness detection)  
- **Realtime Database:** Firebase Firestore  
- **Authentication:** Aadhaar & Phone Number  
- **Storage:** Firebase Storage  
- **Other APIs:** Google Maps API, DigiLocker (optional integration)

---

## 🎯 Use Cases

- Eliminate middlemen in agricultural trade  
- Provide farmers direct access to market and logistics  
- Improve transparency and fairness in crop pricing  
- Apply AI for quality-based produce classification  
- Enable digital transactions and documentation for rural users
